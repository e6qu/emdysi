# Zorro grammatical-acceptability test suite (sample)

- Upstream: https://github.com/phueb/Zorro, `sentences/babyberta/*.txt`,
  commit `687ba433e91a3815e8204a8fc0cf0577303b1660` (2023-01-01).
- License: MIT, Copyright (c) 2020 Philip Huebner (`LICENSE`, copied from
  the repository root).
- Provenance: sentences generated by the author from templates "filled with
  words from custom, human-curated word lists" (upstream README). The words
  were chosen from frequency counts over child-directed speech, Newsela
  text and English Wikipedia; no sentence is copied from those corpora.
  Only single words (not expressive text) derive from them.
- Format upstream: one file per paradigm; odd-numbered lines are
  unacceptable, even-numbered lines acceptable (upstream README and
  `zorro/data.py`). Sentences are lower-case and tokenized (`thing .`).
- Modifications: a sample, not the full data. `sample.tsv` holds the first
  30 pairs of each of the 23 paradigms (690 pairs), in the column layout of
  `corpora/blimp/sample.tsv` (paradigm, `zorro`, phenomenon, acceptable,
  unacceptable), made with `sample.py`. No sentence was changed.
- Use: tests and evaluation only (`crates/emdysi-check/examples/minimal_pairs.rs`).
